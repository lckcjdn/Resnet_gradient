# 实验汇总

本文根据项目中的 `docs/` 记录与 `results/` 产物，对已经完成的实验按数据集进行汇总。结论采用谨慎表述：实验结果提供证据或与假设一致，但不表述为完全证明。

## 总览

| 数据集 | 实验组 | 主要问题 | 主要输出目录 |
|---|---|---|---|
| Toy 1D synthetic grid | 初始化梯度结构 | 随机初始化时 PlainNet / ResNet / PreAct ResNet 的输入梯度是否保持结构 | `results/toy1d_init_gradient_analysis/` |
| Toy 1D synthetic regression | checkpoint 梯度演化 | 训练过程中梯度结构是否改变 | `results/toy1d_checkpoint_gradient_evolution/` |

## 数据集：Toy 1D

### 实验 A：Toy 1D 初始化梯度结构

数据集：Toy 1D fixed grid，`x in [-2, 2]`，256 个点。

模型：PlainMLP、Residual MLP、PreAct Residual MLP、ScaledShortcut Residual MLP。

深度：实际运行 `2, 24, 50`。计划文档中还列过 `4, 10`，但本次结果采用 runtime-limited 深度。

结构：PlainMLP 为前馈 MLP；Residual/PreAct/ScaledShortcut MLP 每个 residual block 提供直接路径。

归一化：Toy 1D runner 未使用 BN；主要比较结构路径本身。

ResNet 缩放参数：初始化实验中运行 `ScaledShortcut lambda=1.0`。未运行 `beta=0.1, 0.3, 1.0`。

minibatch：无 minibatch；固定 256 点逐点求 `df/dx`。

统计：seed `0`，每个模型/深度保存 gradient vector、gradient matrix、correlation/covariance matrix、ACF 和 summary CSV。

### 实验 C：CIFAR-10 初始化输入梯度结构

数据集：CIFAR-10 test split，固定 minibatch indices。

模型：PlainNet、Standard ResNet、PreAct ResNet、ScaledShortcut ResNet lambda=1.0。

深度：实际运行 `20, 56`。注意：用户给出的论文式示例里有 `2, 4, 10, 24, 50`，但本项目 CIFAR 模型采用 CIFAR ResNet/PlainNet 的 `depth = 6n + 2`，所以当前结果是 `20, 56`。

结构：CIFAR PlainNet 与 ResNet 都由两层卷积组成基本 block；ResNet/ScaledShortcut 每个 block 有 skip connection；PlainNet 无 skip connection。

BatchNorm：仓库原始 CIFAR PlainNet、ResNet、PreAct ResNet 都包含 BN。后续 PlainNet ablation 单独比较了 no-BN 和 calibrated BN 设置。

ResNet 使用不同 beta：本次没有运行 `beta=0.1, 0.3, 1.0`。本项目已运行的是 shortcut scaling `lambda=0.5, 0.9, 1.0, 1.1` 的训练统计，以及初始化分析中的 `lambda=1.0`。

minibatch：实际运行 batch size `64`。

统计：实际运行 `5` 个固定 minibatch 平均，seed `0`。计划中推荐 `256` 样本、`30` minibatch；当前结果是 runtime-limited 版本。

梯度定义：per-sample input gradient，`dL_i / dx_i`，展平为 `3072` 维后计算 cosine correlation、relative effective rank、mean gradient norm；空间 ACF 对输入梯度图求平均。

### PlainNet 初始化/归一化消融：collapse 与 shattered-gradient 区分

数据集：CIFAR-10 test split，固定 minibatch indices。

模型：PlainNet-DefaultInit、PlainNet-XavierInit、PlainNet-HeInit、PlainNet-HeInit-BN、PlainNet-OrthogonalInit。

深度：`56`。

结构：Feedforward convnet，无 skip connection。HeInit-BN 变体使用 calibrated BN；Xavier/He/Orthogonal no-BN 变体用于测试初始化对梯度范数的影响。

minibatch：实际运行 batch size `64`。

统计：实际运行 `5` 个固定 minibatch 平均，seed `0`。

诊断规则：若 `input_gradient_norm_mean < 1e-8` 或 `gradient_std < 1e-8`，标记为 `gradient_collapse`，不声称 shattered gradients。

### full_training：分层梯度统计与 identity shortcut 训练表现

数据集：CIFAR-10 train/test full split。

模型：PlainNet-56、ResNet-56、PreActResNet-56、ScaledShortcutResNet-56 lambda `0.5, 0.9, 1.0, 1.1`。

深度：`56`。

结构：PlainNet 为 feedforward convnet；ResNet/PreAct/ScaledShortcut 每个 residual block 有 skip connection。ScaledShortcut 将 shortcut 分支乘以 lambda。

BatchNorm：仓库模型均使用 BN。

训练：30 epochs，batch size `64`，train `50000`，val/test `10000`，learning rate `0.025`，seed `0`，CUDA。

统计：每个 epoch 记录训练/验证 loss/accuracy，并收集 layer-wise conv2 gradient statistics；最终输出 model comparison、gradient stability、lambda ablation。

## 最终结论

1. Toy 1D 和 CIFAR-10 的初始化结果共同提示：默认 PlainNet 的深层输入梯度主要是 collapse/vanishing，而不能直接解释为 white-noise-like shattered gradients。
2. ResNet、PreAct ResNet 和 ScaledShortcut lambda=1.0 在初始化时保留非零输入梯度和更明显的相关/ACF 结构，这与 shortcut connection 提供直接信号与梯度路径的假设一致。
3. PlainNet 初始化消融表明，只有通过 HeInit、HeInit-BN 或 OrthogonalInit 避免近零梯度后，PlainNet 才适合进入 shattered-gradient 分析。后续与 ResNet 比较时应使用 `PlainNet-HeInit-BN` 作为主 PlainNet 设置。
4. full_training 分层梯度统计显示，真实 CIFAR-10 训练中 ResNet/PreAct/ScaledShortcut 的验证精度整体高于 PlainNet；shortcut lambda 接近 1.0 的模型表现较好。
5. residual branch lesion 结果显示删除 residual branch 后精度逐步下降而非 forward path 直接失效，支持 short-path ensemble 的解释。

## 限制与后续工作

- 当前梯度结构实验主要使用 seed `0`，需要多 seed 复现实验。
- CIFAR-10 输入梯度实验是 runtime-limited 设置：batch size `64`，`5` 个 minibatch；如果要严格贴近论文式设置，应补跑 batch size `256`、`30` minibatch。
- CIFAR-10 checkpoint 输入梯度只比较了 epoch `0` 和 final checkpoint，因为 full_training 中间 epoch checkpoint 未保存。
- 本次 Git 整理只保留图表、CSV/JSON/Markdown、metadata 和 manifest；原始 `.npy` 梯度缓存与 `.pt/.pth` checkpoint 权重已清理并由 `.gitignore` 排除，需要时可重新运行脚本生成。
- 本项目运行的是 shortcut lambda `0.5, 0.9, 1.0, 1.1`，不是用户示例中的 `beta=0.1, 0.3, 1.0`。如果报告需要 beta 消融，应另行实现和运行。
