# Documentation Index

This folder holds the written record for the project.

- `theory/`: Background concepts for the presentation.
- `experiment_plan.md`: Experiment goals and setup.
- `experiment_matrix.md`: Model and ablation matrix.
- `expected_figures_and_tables.md`: Required outputs.
- `experiment_log.md`: Chronological run log.
- `process_conclusions.md`: Evidence-grounded conclusions.
- `final_report_outline.md`: PPT/report structure.
- `tables/`: Markdown versions of generated CSV tables.
