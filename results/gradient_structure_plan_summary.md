## Main Findings

- Deep default PlainNet showed near-zero Toy 1D and CIFAR-10 input gradients at initialization in this implementation. The later PlainNet initialization ablation labels this as `gradient_collapse`, not white-noise-like shattered gradients.
- Toy 1D initialization now includes PlainNet-only and residual-family-only gradient curves because combined y-axis plots hide the near-zero PlainNet signal at high depth. Standard ResNet and ScaledShortcut lambda=1.0 are exactly overlapping in the Toy 1D implementation.
- ResNet, PreAct ResNet, and ScaledShortcut lambda=1.0 retained nonzero gradient variation and stronger ACF/spatial structure at initialization.
- PlainNet-HeInit, PlainNet-HeInit-BN, and PlainNet-OrthogonalInit produced non-collapsed CIFAR-10 input gradients and are the appropriate PlainNet candidates for shattered-gradient comparison. `PlainNet-HeInit-BN` is the main setting for future ResNet comparisons.
- Toy checkpoint training fit the synthetic target for residual-style models but not for PlainNet in the quick 10-epoch run.
- CIFAR-10 final full_training checkpoints recovered nonzero gradient structure for all models; residual-style models had higher validation accuracy than PlainNet in the referenced full_training metrics.

## Limitations

- This execution used seed `0` only.
- CIFAR-10 gradient analysis used the runtime-limited setting of 5 fixed minibatches.
- CIFAR-10 checkpoint evolution includes only epoch `0` and final checkpoint because intermediate full_training checkpoints were not available.
- Any PlainNet result with `input_gradient_norm_mean < 1e-8` or `gradient_std < 1e-8` must be described as gradient collapse rather than shattered gradients.
